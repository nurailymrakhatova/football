# Real Madrid Fan Website

## Project topic
A fan website about Real Madrid football club.

## Project goal
Introduce visitors to the club, its players, history and Santiago Bernabéu stadium.

## Team members and page responsibilities

| Team member | Page | Main work |
|---|---|---|
| Amantay Aiymzhan | index.html | Home page |
| Aruzhan Meirkhan | team.html | Players and coach |
| Ayazhan Serikkazy | history.html | Club history |
| Nurailym Rakhatova | stadium.html | Stadium and gallery |

## Technologies
- HTML5
- CSS3
- Flexbox
- CSS Grid
- Media queries for responsive design

## How to open the website
Open `index.html` in a browser or run it with Live Server in VS Code.
